How to install

Gmail: Settings → See all settings → General → Signature → select your signature, clear the box, paste with ⌘V → Save Changes.
Apple Mail / Outlook: same idea: paste into the signature editor.
When images are blocked (Outlook does this for new senders): your details still show, because they're real text, and the logo space shows its name in bold instead.
The logos load from GitHub (1940Farms/szn-social-images, email-footer folder), so they work in any email client.
